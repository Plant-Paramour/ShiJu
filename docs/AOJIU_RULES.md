# 排律拗救约束规格

本文档是生成器与 Web 检查器共同遵循的最小规则集。`P` 表示平，`Z` 表示仄，位置从 1 开始。

## 基本边界

- 小拗不单独检查；奇数位仍可能因为孤平或明确救位而受约束。
- 偶数句以及实际入韵的首句是韵句，其二、四、六位不因拗救而放宽。
- 韵句禁止孤平与三平尾。
- 非韵句允许三仄尾，但关键偶数位的偏离必须符合下列定式。

## 本句救

- 四拗三救：五言非韵句第四位该平而仄时，第三位用平完成本句救。
- 六拗五救：七言非韵句第六位该平而仄时，第五位用平完成本句救。
- 特拗交换：五言第三、四位或七言第五、六位由 `PZ` 换成 `ZP`，仅用于非韵句。

## 孤平自救

- 五言 `ZPZZP` 必须改成 `ZPPZP`，救位是第三位。
- 七言平起韵句的第六位本来就是平声，因此合规则句不会只剩第二位一个非韵脚平声。
- 七言仄起型 `XZZPZZP` 必须改成 `XZZPPZP`，救位是第五位。
- 第四或第六位的平声不能救孤平，也不能据此豁免二四六规则。

## 对句相救

非韵句末关键偶数位该平而仄，且没有在前一奇数位本句救时，对句必须在对应奇数位用平：

- 五言：出句第四位拗，对句第三位救。
- 七言：出句第六位拗，对句第五位救。
- 同一平声字可以同时完成对句相救和本句孤平自救。

实现必须用完整句式验证这些条件，不能把某个偶数位置永久放宽为平仄皆可。
